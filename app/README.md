# IntelliROI Landing

Static product landing page for **IntelliROI** — the Enterprise AI ROI Operating System.

Built with React 19, Vite, Tailwind CSS, Framer Motion, Lenis, and Recharts. No backend required.

## Quick start

```bash
# from repo root
npm run dev

# or from app/
cd app && npm install && npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server |
| `npm run build` | Production build → `app/dist` |
| `npm run preview` | Preview production build |
| `npm run lint` | Run oxlint |
